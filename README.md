# SCOPE INTERNATIONALS — Global Electronics & Tech Exports

A modern, high-performance electronics e-commerce and B2B export platform built with React, Vite, Tailwind CSS, and Supabase.

## 🌟 Highlights & Features

- **Light Aesthetic**: Elegant beige (`#FAF8F5`) canvas, crimson brand accents (`#991B33`), pure white cards, and Playfair Display editorial typography.
- **Export Catalog**: 20 certified electronic products across 5 verticals:
  - Audio & Sound
  - Smart Wearables
  - Charging & Power
  - Pro Peripherals
  - Smart Tech & IoT
- **Technical Specifications**: Realtime hardware specs table for every device (Chipsets, Battery Life, Dimensions, Compliances).
- **Multi-step Checkout**: Smooth 3-step checkout with address management, Cash on Delivery (COD), and Prepaid UPI.
- **Order Tracking**: Comprehensive fulfillment and dispatch tracking pipeline.
- **Admin Dashboard**: Realtime operations portal for catalog management, lot tracking, and order fulfillment.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
